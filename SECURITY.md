# سياسة الأمان / Security policy

**النسخ المدعومة / Supported versions:** `1.0.0-dev` (الفرع / branch `siro-engine/dev`).

**الإبلاغ عن ثغرة / Reporting a vulnerability**

لا تفتح issue عامة لثغرة أمنية. أرسل التفاصيل (الخطوات، النسخة، أثر الثغرة) إلى:
Do not open a public issue for a security problem. Send the details (steps, version, impact) to:

> **support@intaleqapp.com** (Hamza Ayed — Founding Tech Architect & Ecosystem Lead)

**المكوّنات الخارجية / Third-party components**

ثغرات المحرك الأصلي (MapLibre Native، maplibre-gl-js) بتتبع سياسة مشروعهم. أي تحديث لنسخة منهم بيتسجّل بـ `THIRD_PARTY_LICENSES.md`.
Vulnerabilities in the upstream engines (MapLibre Native, maplibre-gl-js) follow their projects' policies. Any version bump is recorded in `THIRD_PARTY_LICENSES.md`.
