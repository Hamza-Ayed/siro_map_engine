# Changelog

## 1.0.0-beta.1

Siro Maps Beta. A fork of [flutter-maplibre-gl 0.27.1](https://github.com/maplibre/flutter-maplibre-gl) (BSD-2-Clause), built on Siro's MapLibre Native fork. Android uses the engine at `io.github.hamza-ayed.siro:siro-native-android-opengl-debug:13.7.1-siro.1` from Maven Central. Known gaps are listed in the README.
